# drydock-eval: paper and data

This branch holds the paper that describes `drydock-eval` and the data behind it. The kit itself is on the branch
`develop` of this repository (tag `v0.4.0`).

Author: Nguyen Minh Thang. November 2026.

| Directory | Content |
|---|---|
| `latex/` | *Contain, Conform, Compare: A Red-Teamed Kit for Evaluating Small Coding Agents on One GPU* (`main.pdf`), its supplementary material (`supplement.pdf`), both in one file (`full.pdf`), sources, scripts, and the outcome data of the case study |

The directory has a `README.md` with the list of files, the scripts, and the commands that recompute the numbers.

No prompt, model output, patch, agent bundle or training data is in this branch. Scripts are under Apache-2.0; text,
figures and data are under CC BY 4.0.
