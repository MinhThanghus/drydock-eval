# drydock-eval: papers and data

This branch holds the papers that describe `drydock-eval` and the data behind them. The kit itself is on the branch
`develop` of this repository (tag `v0.4.0`).

Author: Nguyen Minh Thang. November 2026.

| Directory | Content |
|---|---|
| `latex/` | *Contain, Conform, Compare: A Red-Teamed Kit for Evaluating Small Coding Agents on One GPU* (`main.pdf`), its supplementary material (`supplement.pdf`), both in one file (`full.pdf`), sources, scripts, and the outcome data of the case study |
| `latex_long/` | *Contain, Conform, Compare (Extended Version)* (`main.pdf`): the short paper plus the record of all experiments made with and around the kit, with sources, scripts, and the run-level data of every experiment (`data/`) |

Each directory has a `README.md` with the list of files, the scripts, and the commands that recompute the numbers.

No prompt, model output, patch, agent bundle or training data is in this branch. Scripts are under Apache-2.0; text,
figures and data are under CC BY 4.0.
